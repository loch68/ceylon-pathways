# Hero slideshow images

The hero uses **slide1.svg**, **slide2.svg**, **slide3.svg** by default (lightweight scenic placeholders).

To use your own photos:
- Add images named `slide1.jpg`, `slide2.jpg`, `slide3.jpg` (and optionally `slide4.jpg`, etc.).
- Keep filenames under 30 characters. Use lowercase and hyphens if needed.
- Recommended: 1600×1000px or 2:1 aspect, compressed (e.g. 80% quality). Use WebP or JPG for best performance.

The script will use `.jpg` or `.webp` if present, otherwise falls back to `.svg`.
